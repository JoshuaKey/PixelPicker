# PixelPicker

Pixel Picker is a color guessing game, allowing players to try and "pick" the right color from an RGB value.

Pixel Picker was developed using Java Swing.

## Features
- Displays a random assortment of colors to the screen
- Picks a random color and displays it's RGB value. The player must find the specified color on the screen.
  - Also supports HSL, Hex, Binary, and Decimal fomrat  
- Difficulty which adjusts how many colors are randomly generated
- Customizeable Game Settings
- Help Window
